# Work document templates

These templates support evidence, weekly reviews, handoffs, knowledge, source
digests, role cards and optional project-context narrative. Work owns the authored
output; current tasks/asks/risks and history belong to native items/events.
Select only needed files and attach actual evidence. No template creates a board,
journal or second task register. Follow [work procedures](../SKILL.md).

Shared hook/policy/workflow templates belong to
[templates/internal](../../templates/internal/README.md). Software architecture,
runbook and incident templates belong to the
[software-ops pack](../../packs/software-ops/templates/README.md). Their location
does not change the owning lane or user approval requirements for generated files.
