# Software operations artifact templates

These templates are selected by the Agent when the software-ops procedures apply;
they are not auto-installed and do not change the native process template.

| Artifact | Template | Procedure / output ownership |
|---|---|---|
| Architecture target | [architecture](ARCHITECTURE_TEMPLATE.md) | [architecture](../architecture.md); user-approved target and scoped draft/review authority |
| Runbook and catalog | [runbook](runbook_TEMPLATE.md), [index](runbook_INDEX_TEMPLATE.md) | [runbooks](../runbooks.md); work-owned authored documents |
| Incident and catalog | [incident](incident_TEMPLATE.md), [index](incidents_INDEX_TEMPLATE.md) | [incidents](../incidents.md); work-owned authored documents |

Preserve project paths and existing approved obligations even when the pack is
disabled. A template does not establish deployment, operational readiness or
actual human acceptance. Pack selection follows the shared configuration rules.
