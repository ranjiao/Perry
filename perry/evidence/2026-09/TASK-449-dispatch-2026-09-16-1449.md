## The deviation, and the decision

`affected` **subtracts the slow tier** and prints `held back — <module> is the
slow tier's … run bash tests/run --tier slow` for each. `§ 5.1`'s table does not
say that. It is forced: `select()` draws from every module on disk while `full`
excludes the slow set, so a widened selection would be a strict superset of
`full`, and an executor round would pay `test_tree_guard.py`'s 62.5 s to run the
*cheap* tier. `USER-944` accepted it; `DESIGN-021 § 9` records the reason and the
cost — a change that genuinely touches the harness is told to run `--tier slow`
rather than having it run, so the executor loop can miss a harness regression
until the merge run.
