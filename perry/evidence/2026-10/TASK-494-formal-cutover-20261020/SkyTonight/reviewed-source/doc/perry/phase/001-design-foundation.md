## 阶段焦点

形成项目全景和首轮月球探索的设计依据，通过低保真原型帮助家庭判断体验。
用户已同意先整理文档、再验证原型；初始化只建立管理状态与待办，不执行正式开发。
本阶段不追求上线或实际学习效果达标，家庭真实观测的长期效果留待试用阶段验证。

## 运行规则

- 已确定：亲子同屏、品牌独立、Seestar 兼容示例、先体验再深入。
- 待验证：三个导航入口、教学步骤、页面结构、视觉风格与工程平台。
- Agent 负责研究与提出方案；用户负责体验判断和最终方向确认。
- 当前 README 是已有内容来源；由文档整理任务迁移到 doc/ 的五个设计方向和 overview。
- 每项设计只有一处主要存放位置，其他文档引用；不建立 iterations/。
- 低保真原型可使用模拟数据，必须标明；不将其当作完成的正式应用。
- 未获得用户对具体成品设计的确认，不开启正式实现或自行授予 V5。

## 成本上限

- 新增付费 API、云服务、设备采购预算：0；现有工具使用不另设虚构金额。
- 首条学习链主动投入时间预算：55～80 分钟，分次完成；设备初次设置与跨日期等待单独记录。
- 接近 64 分钟时优先保留观察、解释和验证，压缩可选阅读；超过 80 分钟则拆分或调整方案，不强迫继续。
- Wiring status: doc-only。依赖设计估时和后续试用记录，不声称已由程序强制执行。
- 开发周期、Token 总预算未约定，不作为既有承诺。

## 用户承诺

- 原型可体验后，从家庭使用角度反馈是否看得懂、是否费劲、时间是否合适。
- 设计包完成后确认是否进入正式实现；不要求提供天文或技术决策。
- 反馈在产物可审阅时收集，不因尚未生成的原型提前制造阻塞。

## 用户缺席降级

等待反馈超过 5 天时，继续不依赖该反馈的文档整理、知识来源核对和方案研究。
具体工作顺序按任务依赖查询 perry-task list --json；依赖用户反馈的工作暂停。
不自动锁定导航、教学效果、视觉或技术方案，不自动进入正式实现。

## 阶段缩圈规则

- **KR-progress trigger**: 阶段第 14 天若 commit KRs 完成不足 50%，聚焦单条月球探索链和首次／再次使用两个场景，延后额外主题、第二套视觉方案和坐标系 3D 原型。

## 完成定义

### Must-Have

- doc/ 导航可找到五个设计方向，已定约束与待验证假设分明，未丢失原 README 的实质内容。
- 首条月球探索链科学陈述有来源；分次主动投入 55～80 分钟，等待时间单列。
- 原型覆盖首次探索、再次继续、天气替代、中断恢复，用户反馈有记录。
- 视觉与工程方案与教学及交互一致；用户明确确认进入实现或指出需修改项。

### Nice-to-Have

- 坐标系 3D 教学分镜；不作为首条探索链的前置条件。
- 额外视觉方案或外部家庭反馈。

## 本阶段不做

- 正式应用开发、真实设备连接、生产部署、完整天文推荐系统。
- 全部八个单元的逐课制作或完整 3D 引擎。
- 提前锁定三个主入口或选择正式技术栈。
- 把模拟走查结果声称为孩子已学会或真实家庭试用通过。

### 做得好的部分

- 从文档全景逐步收敛到可点击的完整产品动线，探索与章节推进并行，知识卡可随时查看。
- 根据家长负担反馈，将备课、讲解和材料组织转为App职责，保留解释、预测、验证的学习深度。
- 美学样段、完整原型与对抗评审提供了可以讨论的具体产物；保留失败记录和后续修正。
- 11项任务已关闭且均有KR归属；任务完成不等于总体产品目标达成。

### 不足与范围偏移

- 原型早期只说明局部教学链，不能回答整个App长什么样、如何使用；经用户指出后补齐完整设计。
- 不能由局部光照Demo推断太阳系、天球、星系全部场景的技术泛化能力；仍需后续代表性场景验证。
- 原阶段“不做正式开发”的边界在用户锁定设计并授权框架后发生了明确变化。[框架回执](../evidence/2026-09/TASK-010-result.md)和[双端媒体回执](../evidence/2026-09/TASK-011-result.md)是已授权的额外交付，不用于提高设计评分；阶段状态未及时切换是管理遗漏。
- 成本与学习时长仍为doc-only约束，没有程序强制或家庭实测证据。没有依据宣称实际学习效果、全部双端能力或总体OKR已完成。

### 下一阶段经验与待规划事项

- 先以一条可持续使用的月球探索链定义完整验收，再拆工程任务；以最终锁定体验为基线。
- 将保存、退出、刷新、跨日恢复、原预测与多轮记录保护作为首版核心能力。
- 独立验证Web和真实iPad的媒体、文件、后台、输入及布局；模拟器构建和画面正常只证明其实际覆盖范围。
- 月面素材精修、第三方视频提供方、家庭时间与阅读负担验证继续列为待规划事项，不自动升级为本阶段未完成项。
- 全部八单元制作、生产部署、收费与云同步不由本次结项自动授权。
