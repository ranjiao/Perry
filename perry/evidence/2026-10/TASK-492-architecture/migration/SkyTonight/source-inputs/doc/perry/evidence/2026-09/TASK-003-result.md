| 范围项 | 结果 | 依据 |
| --- | --- | --- |
| A1 首次观察 | 通过 | 20～30 分钟；立即使用已有设备的通用路径，保存区域与初始原话，不要求背术语 |
| A2 照片比较与实验 | 通过 | 15～20 分钟；同一区域比较、固定材料改变光照、记录实验结果与条件预测；区分阴影、暗色和月相 |
| A3 再次验证 | 通过 | 15～20 分钟；保留原预测、采集新证据、检查条件，允许支持／不支持／还无法判断 |
| A4 简短回顾 | 通过 | 5～10 分钟；回看解释变化，记录帮助程度，可继续或休息；未完成真实验证仍保留待办 |

| B2 中断恢复 | 通过 | 四次活动各有保存项与恢复动作；允许缺字段退出，保留原预测，恢复成本计入实际主动时间 |

## 按文档进行的情景走查

以下输入是执行者构造的设计检查案例，不是孩子原话或应用运行记录。

| 输入情景 | 沿文档得到的下一步与判定 | 结果 |
| --- | --- | --- |
| 首次看到一块暗色，孩子说“不知道为什么” | A1 留 E1；A2 用同一区域与灯光实验继续，不因不知道而无法进入 | 通过 |
| 实验后留下“光更接近正上方时影子会缩短”的条件预测 | A2 留 P1；A3 先查条件及区域再看证据，不无条件承诺明天的月面样子 | 通过 |
| 新图比旧图亮，但曝光不同且光照条件未知 | A3 记还无法判断，保留新图和缺失信息；不能认定地貌改变或光照解释已证实 | 通过 |
| 第一晚阴天，没有照片 | B1 可用来源清楚的参考图进入 A1，或只留问题暂停；首次设备观测仍待完成 | 通过 |
| 已有预测，第三次仍阴天 | B1 用参考图／模型核对或等待；A4 可先回顾，真实天空验证不被自动完成 | 通过 |
| 实验做到一半退出，还没有预测 | B2 保留材料与已做步骤；恢复 A2 补实验和 P1，不直接跳到已验证 | 通过 |
| 新图已保存但还没有比较就退出 | B2 找回 P1 与新证据，直接继续比较，不改写旧预测 | 通过 |
| 使用手动望远镜，无法导出照片 | 画观察图、纸笔留底；细节无法匹配时采用参考图，不要求 Seestar 专属能力 | 通过 |
| 阴天演练后实测使总主动时间预计超过 80 分钟 | 压缩重复讲解和扩展，保存并重估；超预算如实记录，不能用拆分或等待类别掩盖 | 通过 |
