## Agent 初步提案

- 1～4人已由D-009确认；15～20分钟是后续完整流程候选，M1当前3～5分钟目标及波次规则以原型范围／CBD为准。
- 角色主武器与机动结构已由 D-015／016 确认；早期独立短冲刺、独立大招叠加不进入首版。
- 固定城市骨架，随机路线、事件、敌人组合及局内 Perk。
- 一局约 4 次安全点三选一，每人独立选择、奖励共享。
- 完成任务后撤离，Boss 只出现在部分任务。
- 友伤开关及默认关闭已确认；轻度第三模式不进入首版，方向输入简化等见具体草案。
- 长期成长以外观和新玩法为主，限制朋友间基础战力差距。

以上均未因用户继续讨论而自动成为定案，所有数字均是未验证的设计假设。
