# Native linkage relations

The old linkage register is frozen history. Current relations are native kernel
edges, read and written through `bin/perry`; read `describe`, `template show` and
`work/reference/kernel.md` first. The shipped template declares allowed endpoint
types, directions and relation kinds. Do not invent a relation name from prose.

Goals owns attribution decisions and their corresponding edge mutations. Work
may propose a task's KR attribution and read it for rollups, but never silently
changes a goals decision. Resolve IDs from current items; ask if ambiguous.
Use actual actor and read sequences when adding/removing edges. Query affected
items after the mutation. Preserve concurrent edges and historical evidence.

Native metric fields compute KR progress by the declared formula. Task counts,
labels or an old markdown percentage do not replace a metric observation.
Attachments link documents; they do not establish a KR relation or semantic
proof. Follow `okr-linkage.md` for the decision procedure.
