# Goals narrative templates

[OKR](OKR_TEMPLATE.md) and [phase](phase_TEMPLATE.md) templates provide reasoning,
measurement intent and retrospective context. Goals owns their authored output.
Current identities, lifecycle, targets and measurements belong to native items.
Select a template only when its narrative is useful, then attach the exact bytes.
See [goals procedures](../SKILL.md) and the
[shared native contract](../../reference/kernel.md).
